## Current process

1. Measure actual stock part and adjoining moving parts before designing views.
2. Generate one isolated donor, preserve prompts and normalize complete views at
   shared isotropic scale. The six-view orthographic branch uses centered framing.
3. Freeze the live workflow, images, settings and conditioning source dependencies;
   submit once, retain raw/remeshed/shape/textured masters and receipts.
4. Review untouched anatomy from top, sole and oblique views before fitting.
5. Exhaust proper rotation, positive uniform scale and placement against actual
   stock attachments. Any later connector edit needs measured scope and attribute proof.
6. Resolve genuine topology defects with bounded evidence; inspect added UV/chart
   color seams. A manifold mesh or higher polycount alone is not anatomical quality.
7. Finalize the practical donor under the current accepted scope, then mirror
   detached geometry between measured stock frames. Preserve rig/animations.
   Check the opposite side independently; disclose accepted measured limits.
8. Calibrate new maps against current effective neighbour materials, including
   controlled palette AO and ORM green roughness. Preserve original maps/normal strength.
9. Collect declared replacements plus exact accepted resources. Preserve fresh
   offline pose/geometry/material/resource proof. Compile every selected new part
   with frozen material dependencies, independently decode native attributes and
   audit actual package contents. Prepare a clean body-only HAK and a separate
   isolated stock comparison module/launcher. The current user authorization
   permits executing the launcher after complete-body readiness.

    offline. Distinguish native selection readiness from final goal acceptance;
    run the authorized automated client checks and publish a full-body animation
