# Superseded foot journals

These byte-exact copies preserve earlier generation, fitting and validation
records. They are historical evidence, not current directions. The active
[foot checkpoint](../../phenotype-foot-checkpoint.md) owns current selection
and instructions. `manifest.json` binds each original file.

The scoped `.gitattributes` disables line-ending conversion for the six hashed
copies. Their original bytes must survive Git storage and checkout; active docs
continue using the repository's normal text policy.
